채널 → 그룹 매핑

매크로 — ASS 매크로 = 샷 1개

각 매크로는 ASS 안에서 PTZ 프리셋 이동 + 장면 전환을 한 번에 처리하는 "샷"입니다. 토큰 = 이 매크로를 발동시키려고 ASS HTTP 서버로 보내는 payload(body), 카메라 = 로테이션이 같은 카메라를 연속으로 안 쓰게 하는 데 씁니다.

트랜지션 — 회전 정책 (매크로 덱)

덱에 매크로를 넣으면 로테이션 간격마다 한 장씩 뽑아 발동합니다. 카드덱처럼 전부 소진하면 다시 셔플해서 반복하고, 카메라 교대를 켜면 같은 카메라가 연속으로 나오지 않습니다. 룰의 액션에서 이 트랜지션을 골라 연결하세요.

룰 (위 → 아래 = 우선순위 높음 → 낮음)

그룹의 활성/비활성 조합이 맞으면 그 룰의 트랜지션이 켜지고, 트랜지션이 매크로를 로테이션합니다. 상단 헤더에서 AUTO·DRY로 엔진을 제어하세요.

활동 로그 (최근 20개)

룰 매칭과 액션 실행 이력. DRY 모드에서도 실제 호출 직전까지 시뮬레이션됩니다.

ASS HTTP 서버 (룰 액션이 호출하는 주소)

모든 룰의 HTTP 액션이 이 주소로 요청을 보냅니다. ASS의 HTTP Servers 탭에서 띄운 서버 주소를 적어주세요. 각 룰의 액션에는 body만 입력하면 됩니다.
